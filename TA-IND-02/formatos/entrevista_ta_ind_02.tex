\section*{Introducción}

Buenos días. Estoy realizando un trabajo universitario sobre el funcionamiento de una clínica veterinaria. Me gustaría hacerle algunas preguntas para conocer cómo manejan las historias clínicas de las mascotas y el control de sus vacunas.

La información se utilizará únicamente para fines académicos. No es necesario proporcionar nombres ni datos personales.

\section*{A. Preguntas sobre el funcionamiento actual}

\begin{enumerate}[leftmargin=*]
  \item ¿Cómo llevan actualmente el registro de cada mascota que llega a la clínica?
  \item Cuando un animal acude por primera vez, ¿qué información consideran importante guardar?
  \item ¿Cómo hacen para consultar el historial de una mascota cuando regresa después de varios meses?
  \item ¿Alguna vez se les ha complicado encontrar una historia clínica o algún dato de un paciente? ¿Qué ocurrió?
  \item ¿Cómo registran las vacunas que recibe cada mascota?
  \item ¿De qué manera controlan las fechas en las que una mascota debe recibir su próxima vacuna?
  \item ¿Qué hacen cuando un propietario no recuerda qué vacunas le han colocado anteriormente a su mascota?
  \item ¿Cómo organizan las citas y las consultas de los animales?
\end{enumerate}

\section*{B. Preguntas sobre el sistema propuesto}

\begin{enumerate}[leftmargin=*, start=9]
  \item Si tuvieran un sistema para registrar las historias clínicas, ¿qué información les gustaría que apareciera en la ficha de cada mascota?
  \item ¿Les parecería útil que el sistema mostrara todas las consultas anteriores de una mascota? ¿Por qué?
  \item ¿Consideran necesario que el sistema permita registrar las vacunas aplicadas, incluyendo su fecha y el tipo de vacuna?
  \item ¿Les ayudaría recibir un aviso cuando una mascota esté próxima a necesitar otra vacuna?
  \item ¿Les gustaría que se pudiera consultar rápidamente qué mascotas tienen vacunas pendientes?
  \item ¿Consideran importante que solamente el personal autorizado pueda modificar las historias clínicas?
  \item ¿Qué tan importante sería poder imprimir o descargar el historial médico de una mascota?
\end{enumerate}

\section*{C. Priorización de características}

Ahora quisiera conocer cuáles de estas funciones consideran más importantes para el trabajo diario de la clínica.

\begin{enumerate}[leftmargin=*, start=16]
  \item Si tuvieran que elegir una sola función, ¿preferirían tener un registro completo de las mascotas, el historial de consultas o el control de vacunas? ¿Por qué?
  \item ¿Qué función consideran indispensable para que el sistema realmente les ayude en su trabajo?
  \item ¿Qué característica creen que podría esperar para una segunda versión del sistema?
  \item ¿Qué problema les gustaría que este sistema solucionara primero?
  \item En general, ¿hay alguna otra función que les gustaría encontrar en un sistema de historias clínicas y vacunas?
\end{enumerate}
